# 🔄 Project-2  

This is a beginner C# console application I created to practice programming fundamentals such as variables, random numbers, conditional statements, user input, and basic arithmetic.<br><br>The project generates two random numbers, compares them, and then allows the user to choose whether to add or subtract the numbers.<br><br>🎯 **The goal of this project was to practice C# logic and program flow while continuing to build my programming fundamentals.**


# 📌 About The Project

This project was created while I was learning the basics of C#.

The program starts by generating two random numbers between 1 and 10. It then compares the two numbers and tells the user whether:

- Number 1 is equal to Number 2
- Number 1 is greater than Number 2
- Number 1 is less than Number 2

After the comparison, the user is asked whether they want to add or subtract the two numbers.

The user enters either:

+

or

-

The program then performs the selected calculation.


# 🎲 Random Numbers

I used C#'s Random class to generate numbers:

Random r = new Random();

num1 = r.Next(1, 11);
num2 = r.Next(1, 11);

This generates two random numbers between 1 and 10.

This was useful practice because random number generation is something that can eventually be used in games, simulations, and other applications.
